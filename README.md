# RTSWorld

RTSWorld is a planned persistent-world multiplayer RTS, developed in Unity 6 with C#, URP and a low-poly 3D isometric presentation.

## Start here
1. Read `AGENTS.md` (maintained separately in the project root).
2. Read `docs/CURRENT_STATE.md`, `tasks/ACTIVE.md` and `docs/HANDOFF.md`.
3. Read the active task and relevant architecture documentation.
4. Inspect the actual Git working tree and Unity project before editing.

## Development
The repository is the source of truth. Claims in handoffs are not substitutes for tests. Only one agent should write to a working tree at a time.
